# ✈️ Skygulf Airways — Airline Analytics Dashboard

> An interactive Power BI airline analytics solution designed to analyze operational performance, flight activity, route-level trends, risk indicators, and business performance.


---

## 📌 Project Overview

This project presents an interactive **Airline Business Intelligence dashboard developed using Microsoft Power BI**.

The dashboard transforms airline operational data into meaningful KPIs and visual insights to support performance monitoring and operational decision-making.

The analysis focuses on:

* Airline performance
* Flight activity
* Route analysis
* Operational trends
* Performance indicators
* Risk analysis
* Interactive business intelligence

> **Note:** This project uses synthetic data and is created for educational and portfolio purposes.

---

## 🎯 Business Problem

Airline operations generate large amounts of data across flights, routes, schedules, performance indicators, and operational activities.

Without centralized analytics, it can be difficult to identify:

* Which routes perform best
* Where operational issues are concentrated
* How performance changes over time
* Which areas require management attention
* Which operational segments present higher risk

This dashboard provides a centralized analytical environment for exploring these patterns.

---

## ❓ Business Questions

The dashboard was designed to answer questions such as:

1. What is the overall airline performance?
2. How does flight activity change over time?
3. Which routes contribute the most to overall activity?
4. Which operational segments perform best or worst?
5. Where are potential operational risks concentrated?
6. How does performance vary across different segments?
7. Which areas require management attention?
8. How do operational indicators change over time?
